- Preserved provider/session, voice, wake-word, action routing, Android assistant role, VoiceInteractionService, microphone foreground service, and sherpa wake model boundaries.
- Mock and OpenAI remain selectable. Spoken and typed input share the same controller/session/TTS pipeline.
- Cloudflare Worker calls the Responses API with `gpt-5.6-luna`; only the Worker sees the key.
- Fixed real HTTP response reading: short responses no longer throw EOF from the OkHttp callback, and read failures reach the coroutine safely.
- Enforced string-only response text and fixed client error messages so raw backend internals cannot appear in normal UI.
- Bounded conversation by complete turns, message count, and 12,000 characters. Clear/provider changes close the session and clear context.
- Preserved displayed conversation across wake events. Contained session creation failures and returned recoverable errors to Idle with the message visible and wake capture rearmed.
- Debug settings now save the backend URL without rebuilding. Typed chat is available before any wake event.
